Design System — v0.1

COLOSSUS

Identidade visual premium/colecionável: uma moldura dourada única do jogo hospedando a cor de cada franquia de origem — Pokémon, Marvel/DC, Yu-Gi-Oh!, Dragon Ball e Futebol.

01 — Cor

Paleta

O ouro é a marca — usado em molduras, selos e texto de destaque. As cores de franquia identificam a origem do personagem sem nunca competir com o dourado.

02 — Tipo

Tipografia

Três papéis, três vozes: uma serifada monumental para o nome do jogo (o "titã"), uma sans neutra para a interface, e uma mono para os números — o dado frio por trás de cada personagem.

Display / Cinzel
Colossus
Logo, títulos de seção — peso 700, sempre com leve tracking
Display / sub
Nome do personagem
Nome do card — peso 600, tamanho 18–20px
Body / Manrope
Escolha seu time antes que o tempo acabe. Cada personagem custa de acordo com o seu overall.
Texto de interface — peso 400/500, 14–16px
Body / ênfase
Confirmar time
Botões e rótulos de ação — peso 700, caixa normal
Data / Space Mono
ATK 088 · DEF 074 · OVR 92
Stats, preços, timers — sempre numérico ou curto

03 — Componente

Card de personagem

Moldura dourada fixa (a marca Colossus) + cor de franquia variável (a origem). O selo no canto mostra o Overall — o número que nasce do percentil, não um enfeite solto. O atributo individual muda por franquia, refletindo o modelo de dados real.
