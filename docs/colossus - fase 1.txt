Fase 1 — Fundações e Modelagem (Concluído)
Este documento consolida as decisões arquiteturais e o schema do banco de dados (Drizzle ORM) que darão base ao core do jogo, resolvendo todas as pendências paralisantes identificadas no levantamento inicial.

1. Decisões Arquiteturais e Regras Refinadas

1.1. Identificadores (NanoID)
⚬ Todas as entidades do banco usarão NanoID (text) como Primary Key (id).
⚬ Motivo: Garante URLs amigáveis, QR Codes rápidos de escanear e previne colisão e raspagem de dados (scraping), sem impactar a performance do SQLite.
⚬ A base de personagens gerará IDs próprios durante a importação, operando de forma 100% independente das APIs externas após a normalização.

1.2. Contrato de Rede (REST vs. WebSockets)
⚬ Rotas REST (Next.js App Router): Usadas exclusivamente para ações de configuração que não exigem sincronia instantânea (Criar Partida, Editar Configurações do Admin, Entrar na Sala/Criar Player).
⚬ Eventos Socket.io: Usados de forma exclusiva a partir do "Iniciar Partida" (Draft, Trava de Personagens, Duelo e Timers). A gestão de tempo não fará inserções no banco a cada segundo; o estado transitório viverá na memória do Node.js, gravando no SQLite apenas nos encerramentos de turno.

1.3. Regras de Draft, Timeout e Expulsão
⚬ Timeout Opcional: O admin pode desligar o tempo do draft. Se estiver ligado e esgotar, o sistema completará o time usando o saldo restante. Caso não haja saldo, o sistema remove cards do mais caro para o mais barato até a conta fechar, distribuindo os cards aleatórios.
⚬ Reconexão Global: O sistema usará um token único (ReconnectToken) válido por 2 minutos cravados para resgatar a sessão do jogador, devolvendo-o exatamente para o estado em que estava (Draft, Lobby ou Duelo).
⚬ Kick de Admin e Limpeza (W.O. Retroativo): O admin pode expulsar jogadores. Se um jogador cair e não voltar em 2 minutos (ou for expulso manualmente), seus duelos (passados e futuros) recebem o status VOIDED. Isso anula os resultados dele, evitando inflar a pontuação de adversários e mantendo a integridade do formato Round-Robin (todos-contra-todos).

1.4. Propriedade Intelectual (Franquias)
⚬ Criação de uma entidade separada para Franchises, mapeando o nome, a cor do Design System e o nome do atributo individual.
⚬ Facilita a alteração em massa dos dados para nomes genéricos (re-skin) caso haja notificações legais sobre direitos autorais no futuro.

2. Schema do Banco de Dados (Drizzle ORM + SQLite)

Abaixo está a modelagem final projetada para rodar em SQLite (com PRAGMA journal_mode = WAL para suportar alta concorrência nas travas em tempo real).
import { sqliteTable, text, integer, real } from 'drizzle-orm/sqlite-core';
import { sql } from 'drizzle-orm';

// ==========================================
// 1. MATCH (Partida)
// ==========================================
export const matches = sqliteTable('matches', {
id: text('id').primaryKey(), // NanoID
status: text('status').notNull().default('LOBBY'), // 'LOBBY', 'DRAFT', 'ACTIVE', 'FINISHED'
teamSize: integer('team_size').notNull(), // 2 a 5
initialBalance: integer('initial_balance').notNull(),
priceCeiling: integer('price_ceiling').notNull(),
draftTimeout: integer('draft_timeout'), // Em segundos. NULL se o admin desligar
createdAt: integer('created_at', { mode: 'timestamp' }).default(sql`CURRENT_TIMESTAMP`),
});

// ==========================================
// 2. PLAYER (Jogador)
// ==========================================
export const players = sqliteTable('players', {
id: text('id').primaryKey(), // NanoID
matchId: text('match_id').notNull().references(() => matches.id),
name: text('name').notNull(),
isAdmin: integer('is_admin', { mode: 'boolean' }).default(false),
isExpelled: integer('is_expelled', { mode: 'boolean' }).default(false), // True se expulso ou caiu e não voltou
sessionId: text('session_id').notNull(), // Vínculo com o cookie HTTP-only
createdAt: integer('created_at', { mode: 'timestamp' }).default(sql`CURRENT_TIMESTAMP`),
});

// ==========================================
// 3. FRANCHISE (Franquias / Propriedade Intelectual)
// ==========================================
export const franchises = sqliteTable('franchises', {
id: text('id').primaryKey(), // NanoID
nickId: text('nick_id').notNull().unique(), // Abreviatura interna (ex: 'poke', 'dbz', 'marvel')
name: text('name').notNull(), // Ex: 'Pokémon' (Pode virar 'Monstrinhos' no futuro)
colorHex: text('color_hex').notNull(), // Ex: '#E0293E' (Vindo do Design System)
individualAttributeName: text('individual_attr_name').notNull(), // Ex: 'SPEED', 'PACE'
});

// ==========================================
// 4. CHARACTER (Personagens - Base global normalizada)
// ==========================================
export const characters = sqliteTable('characters', {
id: text('id').primaryKey(), // NanoID gerado na importação (Desacoplado das APIs externas)
franchiseId: text('franchise_id').notNull().references(() => franchises.id),

name: text('name').notNull(),
imageUrl: text('image_url').notNull(), // URL da imagem re-hospedada no seu storage

// Atributos Universais
attackRaw: real('attack_raw').notNull(),
attackScore: integer('attack_score').notNull(),
defenseRaw: real('defense_raw').notNull(),
defenseScore: integer('defense_score').notNull(),

// Atributo Individual
individualRaw: real('individual_raw').notNull(),
individualScore: integer('individual_score').notNull(),

// Precificação e Escala
overall: integer('overall').notNull(), // Média dos scores normalizados (0 a 100)
});

// ==========================================
// 5. TEAM & TEAM_CHARACTER (Draft com trava real-time)
// ==========================================
export const teams = sqliteTable('teams', {
id: text('id').primaryKey(), // NanoID
playerId: text('player_id').notNull().references(() => players.id),
matchId: text('match_id').notNull().references(() => matches.id),
balance: integer('balance').notNull(),
isConfirmed: integer('is_confirmed', { mode: 'boolean' }).default(false), // Ação irreversível
});

export const teamCharacters = sqliteTable('team_characters', {
id: text('id').primaryKey(), // NanoID
teamId: text('team_id').notNull().references(() => teams.id),
characterId: text('character_id').notNull().references(() => characters.id),
acquiredAt: integer('acquired_at', { mode: 'timestamp' }).default(sql`CURRENT_TIMESTAMP`), // Timestamps resolvem cliques simultâneos
});

// ==========================================
// 6. DUEL & DUEL_ROUND (Gameplay)
// ==========================================
export const duels = sqliteTable('duels', {
id: text('id').primaryKey(), // NanoID
matchId: text('match_id').notNull().references(() => matches.id),
playerAId: text('player_a_id').notNull().references(() => players.id),
playerBId: text('player_b_id').notNull().references(() => players.id),
status: text('status').notNull().default('PENDING'), // 'PENDING', 'ACTIVE', 'FINISHED', 'VOIDED' (Se jogador cair/kickado)
winnerId: text('winner_id').references(() => players.id), // NULL em caso de empate no duelo
});

export const duelRounds = sqliteTable('duel_rounds', {
id: text('id').primaryKey(), // NanoID
duelId: text('duel_id').notNull().references(() => duels.id),
roundNumber: integer('round_number').notNull(),
playerACharacterId: text('player_a_char_id').notNull().references(() => characters.id),
playerAAttribute: text('player_a_attr').notNull(), // 'ATTACK', 'DEFENSE', 'INDIVIDUAL'
playerBCharacterId: text('player_b_char_id').notNull().references(() => characters.id),
playerBAttribute: text('player_b_attr').notNull(),
winnerId: text('winner_id').references(() => players.id), // NULL se der empate de score na rodada
});

// ==========================================
// 7. RANKING ENTRY (O Placar do Torneio)
// ==========================================
export const rankingEntries = sqliteTable('ranking_entries', {
id: text('id').primaryKey(), // NanoID
matchId: text('match_id').notNull().references(() => matches.id),
playerId: text('player_id').notNull().references(() => players.id),
points: integer('points').default(0), // Vitória = 2, Empate = 1
wins: integer('wins').default(0),
losses: integer('losses').default(0),
roundsWon: integer('rounds_won').default(0), // Critério de desempate
});

// ==========================================
// 8. RECONNECT TOKEN (Resgate de sessão)
// ==========================================
export const reconnectTokens = sqliteTable('reconnect_tokens', {
id: text('id').primaryKey(), // NanoID
playerId: text('player_id').notNull().references(() => players.id),
token: text('token').notNull().unique(), // Hash para URL de reconexão
expiresAt: integer('expires_at', { mode: 'timestamp' }).notNull(), // Prazo cravado de 2 minutos
});
